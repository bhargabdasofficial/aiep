# AIEP

Welcome to the **AIEP** repository and Obsidian vault.

This folder serves as both:
- A local workspace/git repository for your project.
- An Obsidian vault for your documentation and notes.

## Setup Instructions

1. **Obsidian**: Open Obsidian and select **"Open folder as vault"**, then choose this `AIEP` directory.
2. **Git/GitHub**: The repository is initialized locally. Once authenticated on GitHub, you can link it to the remote repository.
